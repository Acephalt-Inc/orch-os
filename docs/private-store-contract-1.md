Closed API: `bindWorkspace(workspace, namespace, budget)`, `inspectPartition(binding, budget)`, `preparePartition(binding, budget)`, `partitionPaths(binding)`, `openPrivateFile(binding, name, budget)`, `readBounded(handle, cap, budget)`. Bindings are opaque values registered in a module-private WeakSet at bindWorkspace and frozen with Object.freeze. partitionPaths checks membership; a spread copy or JSON round-trip refuses BAD_BINDING (K1.03). This brand is valid only within the same module instance. `partitionPaths` runtime-validates that brand and returns immutable directory/state/lock paths to trusted importing code; it accepts no path suffix. Namespace is exactly `memory-v1`, `knowledge-v1` or `tasks-v1`, chosen by trusted importing code. Path is `<user home>/.orch-private/<namespace>/personal/<sha256(canonical workspace)>/`; no supplied suffix, collection path or store override. Canonical workspace is an existing non-link directory; reject NUL and observed linked components before realpath. K1.02 compares SHA-256 digests for distinct canonical paths and case aliases; this is path binding, not a permanent identity across workspace moves. Do not use legacy ORCH_HOME.

Resolve the home with realpath (as `src/preferences/store.ts:67` does); components above `.orch-private` are observed but a link there does not refuse; from `.orch-private` through the partition an observed link refuses. Test homes are created under `realpath(os.tmpdir())` because `/var` is a link on macOS. A root/system ancestor does not need the managed 0700/current-UID predicate; do not chmod home/system ancestors. The home environment is location input within the same-account boundary, not an authenticated account selector. Add home-link and unchanged-ancestor controls under K1.02/04.

`inspectPartition` is non-creating; `preparePartition` creates missing private directories, not state. Do not change permissions of existing objects. New folders are created with mode 0700 under the process umask; if a folder this call created is not observed as exactly 0700, prepare refuses it and does not change its mode. Files use 0600; inspect opened-object UID and permission bits, regular-file type and `nlink === 1` before reading. Existing directories must have current UID and `(mode & 0o777) === 0o700`; existing files must have current UID and `(mode & 0o777) === 0o600`. Reject observed special mode bits as well. Use final-component `O_NOFOLLOW`, directory `O_DIRECTORY`, and `O_NONBLOCK` always on macOS and Linux (advisor fact F1; K1.05 FIFO control); ancestor checks are observations, not containment. `openPrivateFile` accepts exactly `state.json` in this card. Missing returns a tagged absent result (K1.01/05); permission, read or validation errors do not become absence.

Parallel 1A decoder integration specification (no sibling implementation import or edit in this card): decoder defaults: maximum input 256 KiB, container depth 8 (root container depth 1), array length 1,000, object keys 32, decoded string 256 KiB UTF-8. Trusted callers may raise total input to 16 MiB, not the other defaults. Exact cap is accepted; cap + 1 refuses. Count bytes across chunks before decoding; reject invalid UTF-8, malformed JSON, duplicate decoded keys including escaped equivalents, forbidden keys `__proto__`, `prototype`, `constructor`, unpaired surrogate strings (String.prototype.isWellFormed() after decoding), non-finite numbers and unsafe integral numbers. Fractional finite numbers may pass syntax parsing; field codecs decide their domain. Build fresh objects; decoded JSON is not configuration. A schema codec must reject unknown fields at its supported depths. The codec is trusted code, not a persisted/schema-selected plugin.

On process.platform === "win32", private admission entries return PRIVACY_UNAVAILABLE before any fs call (K1.11); the dispatcher witnesses bindWorkspace natively and other entries remain gated.

Library errors contain a fixed code and fixed message with no input interpolation or raw error cause. Admission codes: `BAD_INPUT`, `BAD_BINDING`, `UNSAFE_PATH`, `PRIVACY_UNAVAILABLE`, `TOO_LARGE`, `DEADLINE`, `IO_UNAVAILABLE`. The shared fixed error type also reserves `CORRUPT_STATE`, `CONFLICT`, `STALE`, `LOCK_HELD`, `RECOVERY_REQUIRED`, `WRITE_OUTCOME_UNKNOWN`, `CLOCK_ROLLBACK` for successor consumers; it does not implement those behaviours here. INVALID input is distinct from unavailable storage. `budget` is trusted code's monotonic deadline, at most 5,000 ms from operation entry and shared across binding/admission/read steps rather than restarted per helper. No raw errors are written to a stream by this library (K1.12 reporting fixture).

Each entry accepts an optional trailing test seam — an object of functions (platform, uid, clock, UUID, low-level open/read flags and faults) in the pattern of `src/preferences/store.ts:27–35`; it cannot be expressed from arguments, environment or stdin (K1.03/12).
