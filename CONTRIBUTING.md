# Contributing to ORCH-os

ORCH-os is source-available under your choice of the PolyForm Internal Use License 1.0.0 or the PolyForm Noncommercial License 1.0.0 (see [LICENSE](LICENSE)). The copyright holder is Winnicent Zuo, Acephalt Inc.

- **Agreement.** Opening a pull request means you agree to the Individual Contributor License Agreement in [CLA.md](CLA.md) for everything in that pull request.
- **Sign-off.** Every commit needs a `Signed-off-by: Your Name <you@example.com>` line; `git commit -s` adds it. Pull requests with commits that are not signed off are not merged.
- **Before you open a pull request.** `npm ci && npm test` passes. Keep one topic per pull request. Update README.md, README.zh.md and docs/ when behaviour changes.
- **Issues.** Report bugs and requests at https://github.com/Acephalt-Inc/orch-os/issues.
