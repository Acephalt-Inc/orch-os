# Daily brief

Collect the team's current task source, recent results, and waiting decisions. Use
`orch task list --json` for claims and ownership; claims alone are not a task backlog.
Check the relevant records and dates before presenting them. If a calendar connector
is available, read today's calendar in the user's timezone; otherwise ask for the
calendar details needed and mark that section unavailable until supplied. Use available
mail, CRM, or other relevant connectors only when needed, and ask for missing inputs when a
source is unavailable. Do not invent activity or commitments.

Give a concise, ranked brief: open tasks with owners and blockers, decisions waiting,
yesterday's results with evidence, and today's calendar if available. State the basis
for ranking and flag stale or missing information. End with one concrete first action.
